### TOOLS FOR LAKE MONITORING AND FOOD WEB ANALYSES

We are building a set of tools to help you count the plankton in your own lake and assemble a preliminary food web from the results.
Count or upload precounted data, then watch a food web assemble from what you found. These tools are still early versions,
so please treat results as a first draft. We welcome feedback and would be glad to hear how you are using them.

[Open the plankton counters and food web tools](https://jvthaney.github.io/cyanocounter)

### ABOUT THIS KEY

Our key will be continually enlarged, updated and improved. We welcome others to contribute comments and images as well as additional taxa. Those interested should contact James Haney at [jfhaney@unh.edu](mailto:jfhaney@unh.edu).
