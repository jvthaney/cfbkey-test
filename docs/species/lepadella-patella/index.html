Phylum
Rotifera
Class
Monogononta
Order
Ploima

Distinguishing Characteristics

  • Dorsal plate highly arched
  • Stippled collar on dorsal plate
  • Length: lorica 90-108 µm, toes 22-30 µm
  • Width: lorica 65-90 µm
  • Depth: lorica 30-35 µm
  • Terminal foot segment longest
