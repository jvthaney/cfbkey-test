Heterocope septentrionalis

Phylum
Arthropoda
Subphylum
Crustacea
Class
Maxillopoda
Subclass
Copepoda
Order
Calanoida
Family
Temoridae

Distinguishing Characteristics

  • Caudal ramus with three setae
  • Caudal ramus of both sexes with slender outer seta which is approximately equal in length to the ramus
